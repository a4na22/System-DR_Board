🏛️ 정부 정보시스템 DR Plan 검색 시스템

예시 시스템 30개의 사양과 복구 목표는 모두 임의 데이터입니다.

[1. A-A DR 방식] 복구 목표: RPO 0초, RTO 수분 이내 (Active-Active 실시간 동기화)

[2. A-S DR 방식] 복구 목표: RPO 수분 이내, RTO 수시간 이내 (Active-Standby)

[3. 스토리지 복제 방식] 복구 목표: RPO 수시간, RTO 수일~수주 이내 (SAN/NAS 스토리지 비동기 복제)

[4. DR 미대상] 복구 목표: DR 적용 면제 (백업 데이터 기반 수동 복구 체계 유지)

[5. 민간 클라우드이전(PPP포함)]

CSV 파일로 일괄 추가

DR 유형: A-A, A-S, STORAGE, NONE, PPP
